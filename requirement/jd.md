1. Cloud migration / Data Engineering

The main objective is to move toward BigQuery as the central data layer for Clearstate and reduce the number of manual, spreadsheet-based data processes. We are looking for hands-on data engineers who can help us:

​Assess our current Google Sheets / Excel / Drive-based workflows and design a practical target architecture on GCP / BigQuery.
​Build ingestion and ETL/ELT pipelines using Python, SQL, and Google App Script to move and transform data between sheets or into BigQuery.
​Design reusable data models, tables and views that can support internal workflows, client deliverables, dashboards and a future client portal.
​Automate refreshes and incremental loads, with appropriate monitoring, error handling and data-quality checks.
​Reconcile migrated outputs back to our existing deliverables so we can validate completeness and accuracy.
​Create data visualization for internal/data visulation
​Implement appropriate BigQuery performance, cost, IAM/security and documentation standards.
​Build the migration in a reusable way so the same pattern can be applied across additional projects and datasets.

For the profile, strong hands-on Python, SQL, BigQuery/GCP, data modelling and ETL/ELT experience are the core requirements. Experience with orchestration, CI/CD, Cloud Run / Functions / Composer, dbt or Dataform, and working with complex spreadsheet-based source data would also be useful.

For the pilot, we would expect the engineer(s) to take one or more priority datasets through an end-to-end migration, including automated refresh, reconciliation, documentation and handover, so that we have a repeatable migration pattern for the wider programme.
